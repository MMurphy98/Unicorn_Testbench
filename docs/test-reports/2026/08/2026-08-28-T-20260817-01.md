## 正式频谱算法

分析入口：

- `Unicorn_CSA_RevA-COB_woShiled_20260828/analyze_20run_time_only_noise.m`
- `Unicorn_CSA_RevA-COB_wiShiled_20260828/analyze_20run_time_only_noise.m`
- `Unicorn_CSA_RevA-COB_wiShiled_20260828/compare_wi_vs_wo_noise.m`

处理顺序：

1. 按文件名中的 `(1)` 至 `(20)` 自然排序，读取每份 TDMS 的 Channel 0 实际样本。
2. 每份记录独立去除均值，不拼接 20 份波形。
3. 对完整的 1,100,002 点应用 periodic Hamming 窗。
4. 计算正确归一化的单边 PSD，单位为 V²/Hz。
5. 频率间隔为 `50000/1100002 = 0.0454544628101 Hz`；Hamming ENBW 为
   `0.0619465141314 Hz`。
6. 每种条件先对 20 份 PSD 沿运行维等权平均，再开平方得到 ASD，单位为 V/√Hz；不直接平均 ASD
   或 dB。
7. 全分辨率数据用于精确频点和窄带干扰检查；图形另用 1/12 倍频程功率平均显示平滑噪声底。
8. 重复检查先比较紧凑波形签名，再对候选文件逐点 `isequal`，能够发现非相邻重复。

运行命令：

```matlab
run("Unicorn_CSA_RevA-COB_woShiled_20260828/analyze_20run_time_only_noise.m");
run("Unicorn_CSA_RevA-COB_wiShiled_20260828/analyze_20run_time_only_noise.m");
run("Unicorn_CSA_RevA-COB_wiShiled_20260828/compare_wi_vs_wo_noise.m");
```

## 正式结果

下表中的 1 Hz、10 Hz 和 1 kHz 是以对应目标频率为中心的 1/12 倍频程功率平均 ASD。

| 指标 | woShield | wiShield | wiShield / woShield |
| --- | ---: | ---: | ---: |
| 1 Hz ASD | 6.96799 µV/√Hz | 7.30668 µV/√Hz | +0.412 dB |
| 10 Hz ASD | 5.11301 µV/√Hz | 5.28694 µV/√Hz | +0.291 dB |
| 1 kHz ASD | 5.08891 µV/√Hz | 5.12987 µV/√Hz | +0.0696 dB |
| 1 Hz–25 kHz 积分噪声 | 680.520 µVrms | 681.770 µVrms | +0.0159 dB |
| 50 Hz 峰值 ASD | 123.395 µV/√Hz | 147.339 µV/√Hz | +1.540 dB |
| 150 Hz 附近峰值 ASD | 24.0872 µV/√Hz | 18.5602 µV/√Hz | −2.264 dB |

高频 RMS-ASD 滚降（10 kHz–25 kHz 相对 1 kHz–10 kHz）：

- woShield：−2.20922 dB。
- wiShield：−2.18747 dB。

两种条件的高频谱形几乎相同，说明此前观察到的高频下降是可重复的系统响应，可能来自 DUT 带宽、
输出滤波、采集前端/抗混叠响应或其组合，不能靠增加重复次数消除。

## 当日结论

- 在本次测量分辨率和统计量下，屏蔽罩没有降低宽带噪声：1 Hz–25 kHz 积分噪声仅变化
  `+0.0159 dB`，可视为相同。
- 1 kHz ASD 仅变化 `+0.0696 dB`；1 Hz 的 `+0.412 dB` 仍容易受到低频少量 FFT bin 的统计起伏
  影响，不应单独解释为屏蔽导致的退化。
- 屏蔽后 50 Hz 峰值升高 `1.540 dB`，而 150 Hz 附近峰值降低 `2.264 dB`。屏蔽层连接方式可能改变
  工频耦合或回流路径；若要继续定位，应在相同布线下比较屏蔽层悬空、单端接地和双端接地。
- 当前结果是采集通道输出端电压噪声，未折算为 CSA 输入等效噪声；输入等效结果还需要明确总增益。
