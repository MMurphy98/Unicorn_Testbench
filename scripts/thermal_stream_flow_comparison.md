# 27℃固定流量对照测试

`thermal_stream_flow_comparison.py` 在产品控温、定值、不定时模式下执行
**6 → 8 → 6 SCFM**，三段温度目标均为 **27℃**。
每段首次进入 ±1℃后固定记录 300 秒，越界不重置计时。
重复末段 6 SCFM用于检查顺序和热状态变化；单次实验不能推广到其他温度或装夹。

```powershell
python .\scripts\thermal_stream_flow_comparison.py --interval 1 --tolerance 1 --hold-seconds 300 --output-dir .\results\thermal_stream\flow_compare_新编号
```

该命令会控制设备。输出目录必须不存在。默认设备为 `192.168.1.50:3000`，Unit ID 0。
执行前要求设备停止、未处于除霜／整定、初始流量设定 R107=60（6 SCFM）。
绘图依赖在连接前检查。当前入口仅允许写 R107=60 或80，不接受任意流量数值。

每段先停止并确认 C10=0，再修改流量和读回，随后配置27℃并启动。
每秒增加记录 R107 流量设定和 R109 流量输出，保留原有 R102 实际流量记录；
检测到流量设定被外部改变时中止，不自动覆盖更改后继续测试。
R107 的 SCFM×10 编码来自厂家协议；R102/R109 保留原始值，不把响应趋势当成绝对流量校准。

运行结束或异常后，原温度流程先尝试停机；独立恢复步骤再读状态、确认停止并将 R107 恢复为60。
恢复结果写入同级 `<输出目录名>_recovery.json` 和独立报文文件。
必须分别检查 `stop_confirmed`、`flow_restored`；失败结果不会伪装成恢复成功。
改变流量的响应丢失时不盲目重发，恢复步骤先读取状态和设定值。

停止方式为在输出目录创建 `STOP` 文件，或在执行终端按 Ctrl+C。
正常采温流程沿用已有错误处理和停机确认；不调整 PID、温度斜率、流量输出寄存器或外部压缩机电源。

新增实验客户端只显式允许两个 R107 值；普通温度客户端仍禁止流量写入。
通用序列入口增加可选阶段表、停机配置回调、额外记录字段与快照文件；默认三温度行为保持原有配置。
