# Data

原始测试数据不直接提交到 Git。每个任务应在根目录 `测试安排.md`、测试结论文件和 PR 中
记录稳定的原始数据 HTTPS 链接、版本或哈希、访问权限和必要的格式说明。

仅体积小、无敏感信息且对测试复现不可或缺的 fixture 才可入库；这类文件应放在对应的
`matlab/tests/fixtures/`，并在测试结论中说明来源。

从原始数据得到的小型处理结果可以放在 `data/processed/` 并进入版本控制，但必须同时记录生成方法、
单位、SHA-256 和能力边界。处理结果可用于无原始数据时复图和审查数值，不能替代完整时域数据进行
Welch 参数复算。
